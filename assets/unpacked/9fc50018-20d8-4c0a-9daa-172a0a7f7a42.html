Project Context

KidLoop is a personal UX project addressing the second-hand children's clothing market. Parents often struggle to find safe, trustworthy pre-loved kids' clothing — existing marketplaces feel unclear about product condition, unsafe and inconvenient for both buying and selling. KidLoop aims to create a transparent, safe, and easy-to-use platform where parents can buy and resell children's clothing while encouraging sustainable shopping habits. This project uses secondary research and competitor analysis to identify potential user needs and behaviours.

The problem
Buying second-hand feels like a gamble
Condition is described inconsistently, so parents can't judge safety or wear before buying.
Listing an item takes too long, so outgrown clothes stay in the closet.
Payment and delivery happen off-platform, with no protection either way.
The solution
One loop: buy, outgrow, pass on
A fixed three-step condition badge on every card, chosen from the same list by every seller.
A four-step sell wizard — photo, details, price, preview — finished in under three minutes.
In-app checkout with free delivery included on every order.

Key takeaways
01 — Trust is a layout problem
Condition had to be visible at card level, not buried in the detail page — it changed the whole grid.
02 — Two modes, one home
Buyer and seller as a toggle rather than separate apps kept the loop — and the navigation — short.
03 — Build it to feel it
Prototyping in the browser exposed spacing and scroll problems that static frames hid completely.
